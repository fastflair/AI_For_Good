OPTIONAL TOOLS
==============

The core application has no external molecular-builder dependency.

Optional inputs/tools:

1. PDB/mmCIF structure files
   - Preferred when an experimental structure for the sequence/conformation exists.
   - Uploaded coordinates are used directly by the projection layer.

2. NCBI / Ensembl / ZFIN network access
   - Used only for automatic current-sequence retrieval.
   - The bundled hoxb1a-201 sequence makes the core workflow usable offline.

3. Camera + image capture
   - Required only for physical cymatics verification.

4. Accelerometer, laser vibrometer, microphone, or electrical response measurement
   - Strongly recommended for resonator calibration.
   - These measurements can be reduced to the calibration CSV format supported by the app.

Not required:
- External molecular builders
- Molecular dynamics packages
- Quantum chemistry packages

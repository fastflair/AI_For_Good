EXPERIMENTAL PROTOCOL
=====================

Goal: test whether an actual vibrating resonator can reproduce a DNA-derived 2-D target sufficiently to support the computational inverse model.

A. CALIBRATE THE RESONATOR
--------------------------
1. Measure circular plate radius and thickness.
2. Record material and estimate density, Young's modulus, and Poisson ratio.
3. Document mounting/boundary condition.
4. Mount the actuator at a known radial and angular position.
5. Run the sequential calibration WAV or an independent frequency sweep.
6. At each resonance, photograph the pattern and record frequency and response.
7. Build a CSV:

   frequency_Hz,response

8. Load the CSV into the application.

B. GENERATE THE DNA TARGET
--------------------------
1. Use a sequence with documented provenance.
2. For gene-level artwork, use Rolling-turn ensemble axial density.
3. Save the literal projection, molecular target, conditioned target, and mode table.
4. Do not use musical note quantization for the physical experiment.

C. TEST INDIVIDUAL MODES
-------------------------
1. Drive the strongest single candidate at its exact modeled/measured frequency.
2. Record the image.
3. Repeat for each major candidate.
4. Compare each image to the expected mode field.

D. TEST THE MULTI-TONE DRIVE
----------------------------
1. Use the exact-Hz primary physical-drive WAV.
2. Keep amplitude low initially and increase only as required by the apparatus.
3. Keep actuator location fixed.
4. Record drive parameters and camera images.
5. Compare the measured image to the DNA target after registration.

E. IMAGE COMPARISON
-------------------
Report:
- spatial RMSE
- Pearson correlation
- Dice and IoU where thresholding is meaningful
- 95th-percentile boundary distance where a clear boundary exists
- angular-harmonic correlation

Also inspect the registered images visually.

F. IMPORTANT CONTROLS
---------------------
Run controls using:
1. a randomized sequence of the same length and composition,
2. a homopolymer control,
3. the same target generated from a different projection method,
4. repeated measurements of the same resonant mode,
5. the same plate with a different actuator location.

The purpose of these controls is to determine whether sequence-specific differences survive the projection, inverse fitting, and physical resonator response.
